# AulaSegura

Plataforma inteligente de evaluaciones virtuales enfocada en seguridad, monitoreo en tiempo real e integración con inteligencia artificial.

---

# Descripción

AulaSegura es una plataforma web desarrollada principalmente con HTML, CSS y JavaScript Vanilla, diseñada para permitir la realización de exámenes virtuales de manera segura, moderna e interactiva.

El sistema incorpora funcionalidades avanzadas como:

- Monitoreo en tiempo real
- Bloqueo anti-trampa
- Pantalla completa obligatoria
- Generación automática de preguntas con IA
- Soporte para ecuaciones matemáticas
- Renderizado con MathQuill
- Chat profesor ↔ estudiante
- Gestión completa de exámenes

El objetivo del proyecto es ofrecer una solución moderna para instituciones educativas y docentes que necesiten realizar evaluaciones virtuales de forma confiable.

# Funcionalidades de seguridad

- Bloqueo de salida de pantalla completa
- Detección de comportamiento sospechoso
- Sistema de sanciones automáticas
- Bloqueo remoto por parte del profesor
- Monitoreo continuo durante el examen

- Monitorear estudiantes en tiempo real
- Bloquear y desbloquear estudiantes

- Comunicarse mediante chat en vivo

- Responder ecuaciones matemáticas

- Comunicarse con el profesor
